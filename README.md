## Olá! Eu sou o Giovanni Micheletti Torres!

Ao atuar com dados, desenvolvi habilidades essenciais como análise estratégica, inovação, adaptabilidade e visão orientada a resultados — competências fundamentais para quem atua com Inteligência de Dados.
